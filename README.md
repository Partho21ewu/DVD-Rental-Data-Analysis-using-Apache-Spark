# DVD Rental Data Analysis using Apache Spark

## Overview

This project analyzes transactional data from the DVD Rental database using Apache Spark (PySpark) within the Databricks environment. The objective was to explore customer payment behavior, evaluate staff performance, analyze rental trends, and demonstrate large-scale data processing capabilities.

The project showcases how distributed data analytics can be used to extract actionable business insights from relational datasets.

---

## Objectives

* Explore and analyze payment transactions.
* Measure customer spending behavior.
* Identify top-performing staff members.
* Analyze rental activity over time.
* Perform data integration through joins.
* Demonstrate scalable analytics using Apache Spark.

## Analysis Performed

### 1. Data Import and Exploration

* Loaded payment and rental tables into Spark DataFrames.
* Validated schema and sample records.
* Performed initial exploratory analysis.

### 2. Total Number of Payments

* Calculated total transaction count.
* Measured dataset size and activity level.

### 3. Average Payment Amount

* Computed average customer payment using Spark aggregation functions.
* Evaluated customer spending behavior.

### 4. Staff Performance Analysis

* Grouped payment data by staff member.
* Calculated total revenue generated by each staff member.
* Identified the highest-performing employee.

### 5. Rental Activity by Month

* Extracted month values from rental dates.
* Aggregated rental counts by month.
* Evaluated seasonal rental trends.

### 6. Join Operations

* Joined payment and rental datasets using rental_id.
* Generated integrated business insights.
* Calculated total payments associated with rental activities.
